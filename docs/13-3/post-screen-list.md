# 投稿アプリ
## 画面一覧

| ID | 画面名 | 役割 | 主な利用者 |
|:---|:-------|:----------|:---|
| SC-01 | 投稿アプリタイトル画面 | ログイン中はログイン者の名前を表示し投稿一覧画面へ移動する入口を見せる、そうでない場合はログイン・アカウント作成画面へ移動する入口を見せる（最初に開く画面） | 利用者 |
| SC-02 | アカウント作成画面 | 名前・メールアドレス・パスワードを入れてアカウント作成する | 利用者 |
| SC-03 | ログイン画面 | メールアドレスとパスワードを入れてログインする | 利用者|
| SC-04 | 投稿一覧画面 | 全ての投稿を新しい順に見せ、自分の投稿にだけ編集と削除の入口を出す| 利用者 |
| SC-05 | 投稿編集画面 | 自分の投稿のタイトル・カテゴリ・本文を編集する | 利用者 |
