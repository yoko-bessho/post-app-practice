# 画面項目定義

| 項目名 | 種類 | 必須 | 内容 |
|:---|:---|:---|:----------|
| つぶやき投稿アプリ | リンク | - | 押すと投稿一覧画面へ移る |
| 画面見出し | 表示 | - | 「ポストを編集」 |
| タイトル | 入力(１行) | 必須 | 投稿のタイトル。開いた時は今の値が入っている |
| トピック | 選択 | 必須 | 登録されているカテゴリから一つ。開いた時は今のカテゴリの値が入っている |
| 本文 | 入力（複数行） | 必須 | 投稿の内容 |
| 更新 | ボタン | - | 押すと投稿を更新して投稿一覧画面へ戻る |
| キャンセル | リンク | - | 押すと投稿の内容は変更せずに投稿一覧画面へ戻る|
