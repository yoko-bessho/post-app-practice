# つぶやき投稿アプリ
##　入力チェック表

| 画面 | 項目 | 必須 | 文字数・桁数 | 形式・値の範囲 | 他の項目との関係 |
|:-- |:--- |:--- |:--- |:--- |:-------- |
| 投稿編集画面 | タイトル | 必須 | 255文字以内 | 文字列 | - |
| 投稿編集画面 | トピック | 必須 | - | 登録カテゴリのどれか一つ | - |
| 投稿編集画面 | 本文 | 必須 | 制限なし | 文字列 | - |

タイトルの255文字以内は、データベース登録の設定値に合わせたものです。
本文の文字数制限なしですが、データベース登録の設定上は21,845文字以内です。一部の漢字登録時は上限はより少なくなります。
投稿一覧に並べた時に読みやすい長さを考えると、50文字や100文字にする案もあります。本文の制限なしも同じでデータベース登録上以外の根拠がありません。どちらも「この長さで問題ないですか」と確認事項リストへ回します。
