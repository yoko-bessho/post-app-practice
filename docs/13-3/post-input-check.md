# つぶやき投稿アプリ
##　入力チェック表

| 画面 | 項目 | 必須 | 文字数・桁数 | 形式・値の範囲 | 他の項目との関係 |
|:-- |:--- |:--- |:--- |:--- |:-------- |
| 投稿編集画面 | タイトル | 必須 | 255文字以内 | 文字列 | - |
| 投稿編集画面 | トピック | 必須 | - | 登録カテゴリのみ | - |
| 投稿編集画面 | 本文 | 必須 | 制限なし | 文字列 | - |

タイトルの255文字以内は、データベース登録の設定値に合わせています。
本文の文字数制限なしですが、データベース登録の設定上は21,845文字以内です。一部の漢字登録時は上限はより少なくなります
