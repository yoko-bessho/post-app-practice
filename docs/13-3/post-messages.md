# つぶやき投稿アプリ
## メッセージ一覧

| 画面 | 出る画面 | 区分 | メッセージ |
|:-- |:--- |:--- |:--- |
| 投稿編集画面 | タイトルが空のまま「更新」を押した | エラー | タイトルを入力してください |
| 投稿編集画面 | タイトルが文字列以外 | エラー | タイトルは文字列で入力してください |
| 投稿編集画面 | タイトルが255文字を超えている | エラー | タイトルは255文字以下で入力してください |
| 投稿編集画面 | 本文が空のまま「更新」を押した | エラー | 本文を入力してください |
| 投稿編集画面 | 本文が文字列以外 | エラー | 本文は文字列で入力してください |
