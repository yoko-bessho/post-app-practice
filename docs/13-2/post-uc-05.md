#### UC-05: 投稿を削除する

- **アクター**: ログイン済み利用者
- **事前条件**:
    - 利用者としてログインしている
    - 投稿者本人の投稿が対象である
- **基本フロー**:
    1. ログイン済み利用者が投稿の「削除」ボタンを押す
    2. システムが投稿の削除実行の確認認面を表示する
    3. ログイン済み利用者が「削除する」ボタンを押す
    4. システムが投稿を削除する
- **代替フロー**:
    - 3a. 直接自分以外の投稿を削除する送信をした場合：システムはエラーメッセージを表示し、投稿は削除されない
- **事後条件**: 対象の投稿が表示されない
- **受け入れ条件**:
    - [ ] 自分の投稿に削除ボタンが表示される
    - [ ] 削除ボタンを押下すると、対象の投稿が削除される
    - [ ] 自分以外の投稿を削除しようとすると、エラーメッセージが表示され、投稿は削除されない
