#### UC-05: 商品を受け渡す

- **アクター**: 店員
- **事前条件**: 受け取り前の注文が１件以上ある
- **基本フロー**:
  1. 店員が注文一覧画面を開く
  2. システムが受け取り前の注文を、注文番号と共に一覧で表示する
  3. 店員がお客さんから伝えられた注文番号を選ぶ
  4. システムが注文の商品と個数を表示する
  5. 店員が商品を渡し、「受け渡し済みにする」を押す
  6. システムが受け渡し済みとして記録し、受け取り前の一覧から外す
- **代替フロー**:
  - 2a.お客さんからのキャンセル操作あり: キャンセルされた注文がグレーアウトし、「注文がキャンセルされました」と表示される
  - 3a. 伝えられた注文番号が一覧にない場合：　システムは該当する注文がない旨を表示する
  - **事後条件**: 注文内容が受付済みと表示され、受け取り前の一覧に表示されなくなる
  - **受け入れ条件**:
  - [ ] 注文一覧画面に、受け取り前の注文番号、注文内容が表示される
  - [ ] 注文番号で注文を選ぶと、その注文の商品と個数が表示され
  - [ ] 「受け渡し済みにする」を押すと、その注文が受け取り前の一覧から消える
