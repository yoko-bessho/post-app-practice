#### UC-04: 投稿を編集する

- **アクター**: ログイン済み利用者
- **事前条件**:
    - 利用者としてログインしている
    - 投稿者本人の投稿が対象である
- **基本フロー**:
    1. ログイン済み利用者が投稿一覧画面で、自分の投稿の「編集」ボタンを押す
    2. システムが投稿の編集認面を表示する。編集画面には今の投稿の内容（タイトル、カテゴリ、本文）が入った状態
    3. ログイン済み利用者が、タイトル、トピック、本文のいずれかを編集し、更新ボタンを押下する
    4. システムが投稿を書き換え、投稿一覧画面へ戻す
- **代替フロー**:
    - 1a. 直接自分以外の投稿を編集するURLを開いた場合： システムは403エラーで権限がないことを表示し、編集画面を表示しない
    - 3a. タイトル、トピック、本文が空欄の状態のまま編集ボタンを押下した場合： システムはエラーメッセージを表示し投稿を書き換えない
    - 3a. キャンセルボタンを押下した場合: システムは元の投稿のまま投稿一覧画面に戻る
- **事後条件**: 対象の投稿の編集内容が更新され、投稿一覧画面に反映される
- **受け入れ条件**:
    - [ ] 投稿一覧画面で、自分の投稿にだけ編集ボタンが表示される
    - [ ] 編集ボタンを押下すると編集画面が表示される
    - [ ] 内容を書き換えて更新ボタンを押すと、投稿一覧画面に書き換えた内容が表示される
    - [ ] 編集画面のタイトル、トピック、本文のいずれかが空欄のまま更新ボタンを押下した場合、エラーメッセージが表示され、投稿の内容は変わらない
    - [ ] 自分以外の投稿を削除しようとすると、エラーメッセージが表示され、投稿は削除されない
