#### UC-04: 投稿を編集する

- **アクター**: ログイン済み利用者
- **事前条件**:
    - 利用者としてログインしている
    - 投稿者本人の投稿が対象である
- **基本フロー**:
    1. ログイン済み利用者が投稿の「編集」ボタンを押す
    2. システムが投稿の編集認面を表示する
    3. ログイン済み利用者が、タイトル、トピック、本文のいずれかを編集し、更新ボタンを押下する
    4. システムが投稿を編集し、投稿一覧画面に編集された投稿を表示する
- **代替フロー**:
    - 1a. 直接自分以外の投稿を編集するURLを送信した場合： システムは403エラーを表示し、編集画面を表示しない
    - 3a. タイトル、トピック、本文に空欄の状態のまま編集ボタンを押下した場合： システムはエラーメッセージを表示する
    - 3a. キャンセルボタンを押下した場合: システムは元の投稿のまま投稿一覧画面に戻る
- **事後条件**: 対象の投稿が表示されない
- **受け入れ条件**:
    - [ ] 自分の投稿に編集ボタンが表示される
    - [ ] 編集ボタンを押下すると編集画面が表示される
    - [ ] 更新ボタンを押下すると、対象の投稿が編集後の投稿に更新された更新一覧が表示される
    - [ ] 編集画面のタイトル、トピック、本文を編集の不備で更新ボタンを押下した場合、入力中の文字は保持されたまま
    - [ ] 自分以外の投稿を削除しようとすると、エラーメッセージが表示され、投稿は削除されない
