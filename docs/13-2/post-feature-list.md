# 投稿アプリの仕様書より

## 機能一覧

| ID | 機能　| 主な利用者 |
|:---|:--------|:----|
| F-01 | ユーザー登録 | ログイン前の利用者 |
| F-02 | ログイン | ログイン者 |
| F-03 | ログアウト | ログイン者 |
| F-04 | 投稿の編集 | 投稿者本人 |
| F-05 | 投稿の削除 | 投稿者本人 |
| F-06 | 投稿の閲覧 | ログイン者 |

## できること

- ユーザー登録・ログイン・ログアウト
- 投稿の一覧表示（投稿者の名前とカテゴリつき）
- 投稿の編集（タイトル・カテゴリ・本文）と削除
- 自分の投稿だけを編集・削除（他人の投稿は編集・削除ボタンが出ず、URL を直接開くと 403 になります）
