#### UC-02: 商品を注文する

- **アクター**: お客さん
- **事前条件**: なし
- **基本フロー**:
  1. お客さんが、商品一覧画面で注文したい商品と個数を選び、「カートに入れる」を押す
  2. システムが注文内容と合計金額を表示する
  3. お客さんが「支払いに進む」を押す
  4. システムが支払いの画面を表示する
  5. お客さんが支払いの手続きを行う
  6. システムが注文を登録し、注文番号を表示する
- **代替フロー**:
  - 5a. 決済が完了しなかった場合： システムはエラーメッセージを表示し注文内容は登録されない
- **事後条件**:
    - 注文内容が確定登録され、決済が完了している
    - 発行された注文番号と注文状況を確認できる
- **受け入れ条件**:
  - [ ] 商品一覧画面で商品と個数を選ぶと、注文内容と合計金額が表示される
  - [ ] 決済が完了すると、注文番号が表示される
  - [ ] 決済が完了しないまま終わると、エラーメッセージが表示され、注文は登録されない
